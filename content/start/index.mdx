distribution focused on usability, Persian-language support, and the KDE
Plasma desktop. This section takes you from an empty machine to your first

## The three core skills

Almost everything in this portal builds on three skills. Learn them in this
order:

1. **Build packages.** Every piece of Parch software, from the kernel to the
   Welcome app, ships as a pacman package. See [Packaging](/packaging/).
2. **Build ISO images.** Releases and custom editions are assembled with the
   archiso tool from per-edition profiles. See [ISO Building](/iso/).
3. **Follow the HIG.** First-party apps share one design language. See
   [Human Interface Guidelines](/hig/).
