# Platform Architecture

Parch is Arch Linux with a purpose-built layer on top. Understanding where
that layer begins and ends is the difference between working *with* the
distribution and fighting it.

## The one-picture view

```text
┌─────────────────────────────────────────────────────┐
│ First-party apps: Pastor, Welcome, Update, PKM …    │  Parch
├─────────────────────────────────────────────────────┤
│ Desktop integration: themes, SDDM/GRUB/PLYMOUTH     │  Parch
├─────────────────────────────────────────────────────┤
│ Installer: Calamares (parch flavor)                 │  Parch flavor
├─────────────────────────────────────────────────────┤
│ world repository (parch packages) · Void (testing)  │  Parch
├─────────────────────────────────────────────────────┤
│ ISO profiles (parch-iso-*) built with archiso       │  Parch
├─────────────────────────────────────────────────────┤
│ KDE Plasma / GNOME / XFCE / Hyprland                │  upstream
├─────────────────────────────────────────────────────┤
│ pacman + ALPM · systemd · linux kernel · Arch repos │  upstream
└─────────────────────────────────────────────────────┘
```

Everything below the ISO-profiles line comes from upstream and follows
upstream behavior. Everything above it is Parch's responsibility, and is
documented in this portal.
