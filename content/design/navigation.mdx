# Navigation

## Tabs

Tabs switch between peer views at the same level. They never nest inside
dialogs, and tab labels never change while visible.

## Sidebar navigation

Applications with more than ~5 destinations use a sidebar (the Parch Store,
Settings, and the portal itself all do):

- Sections are icon + label; the active destination is marked with the accent
  color and a bolder weight.
- The sidebar scrolls independently of content.
- On narrow widths it collapses into a drawer, the same tree, same order.
