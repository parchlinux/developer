# Iconography

## Application icons

First-party Parch applications use rounded-square (`border-radius: 22%`)
full-color icons that survive both themes. The gallery below uses the real
icons shipped with Parch:

Icon files are provided as SVG where possible, installed to
`/usr/share/icons/hicolor/scalable/apps/` with the app's desktop-file name.

## UI glyphs

Interfaces use a single outline glyph family at 16px (inline) or 18–20px
(controls), 1.5px stroke, currentColor. The portal standardizes on
[Lucide](https://lucide.dev); GTK and Qt apps use their toolkit equivalents
with the same intent.

<Checklist>
  - Glyphs decorate after they clarify: every icon next to text is redundant
    but harmless; every icon standing alone needs a tooltip or label.
  - No emoji as UI icons.
  - Don't mix filled and outline styles for the same concept.
  - RTL: directional glyphs (arrows, back/forward) mirror; non-directional
    glyphs (settings, search) do not.
</Checklist>

## Brand marks

The Parch logomark exists in dark-on-light and white-on-dark variants and
must never be recolored, rotated, or placed on busy imagery. It is not a UI
glyph, don't use it as a back button.
