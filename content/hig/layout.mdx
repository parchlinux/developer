# Layout, spacing & density

## The grid

All spacing derives from a 4px base unit. Use the spacing scale (4, 8, 12,
16, 24, 32, 48) instead of arbitrary values; adjacent elements sit at the
closer scale step, groups separate at a wider one.

## Content width

Reading content caps at ~768px (60–80 characters). Application bodies may use
the full window, but list columns stay within ~900px to keep scan paths short.

## Alignment

- Start-aligned text in both directions (left in LTR, right in RTL), center
  alignment is for empty states and onboarding only.
- Forms label above the field, start-aligned; related controls group into
  cards or bordered groups.
- Numeric columns in tables align to the end (right in LTR).

## Density & scaling

Applications must remain usable at 100%, 125%, and 150% interface scaling and
when the system font size changes. Prefer rem-based sizing; avoid fixed
pixel heights on text containers; test with Estedad, which runs taller than
Saira at the same size.
