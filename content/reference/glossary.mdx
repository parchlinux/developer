# Glossary

| Term | Definition |
|---|---|
| **airootfs** | The directory in an ISO profile whose contents are overlaid onto the live system's root. See [airootfs customization](/iso/airootfs-customization/). |
| **ALPM** | Arch Linux Package Management library; the engine under pacman. |
| **AUR** | Arch User Repository; community PKGBUILDs built by users. Where generic Arch packages belong. |
| **bootmodes** | The `profiledef.sh` list of boot combinations a profile supports (BIOS/UEFI × USB/CD). |
| **Calamares** | The framework-based installer Parch uses, with a Parch flavor package for branding and configuration. |
| **chroot** | A process view of a filesystem rooted elsewhere; clean chroot builds verify packages against only their declared dependencies. |
| **DKMS** | Dynamic Kernel Module Support; rebuilds out-of-tree drivers (NVIDIA, broadcom-wl) against installed kernels. |
| **DKMS module risk** | Out-of-tree modules must match the kernel version; kernel upgrades trigger rebuilds. |
| **EFI system partition (ESP)** | FAT32 partition (512 MiB in Parch presets) holding UEFI bootloaders. |
| **Estedad** | The Persian UI typeface shipped by Parch. See [typography](/hig/typography/). |
| **HIG** | Human Interface Guidelines; this portal's design rules for apps. See [HIG](/hig/). |
| **initramfs** | The early-userspace image that mounts the real root; generated by mkinitcpio. |
| **libadwaita** | The GTK4 companion library providing Parch-HIG-aligned widgets; used by parch-welcome and PKM. |
| **mkarchiso** | The archiso build command that turns a profile into an ISO. |
| **mkinitcpio** | Arch's initramfs generator; configured via `/etc/mkinitcpio.conf.d/` and presets. |
| **Namcap** | The Arch PKGBUILD and package linter. |
| **pacman** | Arch's package manager; unchanged in Parch. |
| **Pastor** | The Parch Store application (Rust). |
| **PKGBUILD** | The bash script describing how a package is built. See the [reference](/packaging/pkgbuild-reference/). |
| **pkgctl** | Devtools CLI for chroot builds (`pkgctl build`) and PKGBUILD checkout (`pkgctl repo clone`). |
| **profiledef.sh** | The ISO profile's metadata script: name, label, bootmodes, file permissions. |
| **repo-add** | Tool that regenerates a pacman sync database from package files; how world's `world.db` is maintained. |
| **Rolling release** | A distribution model with continuous updates and no version milestones; the ISO is a snapshot. |
| **RTL** | Right-to-left script direction (Persian); see [RTL & Persian](/hig/rtl-and-persian/). |
| **shiki** | The syntax highlighter used by this portal's code blocks. |
| **SigLevel** | pacman's signature-verification setting; `Never` today for world, `Required` is the proposed target. |
| **squashfs** | The compressed read-only filesystem holding the live system inside the ISO. |
| **SDDM** | The display manager on Plasma editions, themed by `parch-sddm`. |
| **systemd-networkd** | The network configurator used in the live environment. |
| **Void** | Parch's testing repository; packages graduate to world. |
| **world** | Parch's stable package repository, served from GitHub. |
